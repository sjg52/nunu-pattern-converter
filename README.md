# 努努排版小工具

努努图纸部件识别与自动排版工具。上传努努图纸（支持多图、非白底色），自动识别部件并基于 MaxRects 算法进行无重合排版，可设置部件间距、来源尺寸等参数，适合手工/缝纫制版场景下的图样排料。

## 功能特性

### 图纸排版
- 多图上传，自动识别图纸中的部件
- 识别后可手动删除/恢复任意部件（悬停可在预览图上定位）
- 排版按需生成：改参数、删部件只标记为待更新，点「生成排版」才真正计算，避免反复重算卡顿
- 形状感知的 MaxRects 无重合排版（碰撞检测优化）
- 支持非白色底色图纸
- 可配置部件间距、来源尺寸等参数

### 配色推荐（色卡匹配）
- 上传参考图 → 点击取色 → 输出最接近的色号 Top 6
- 取色用**周围一圈的中位色**，抗线稿边缘、毛绒纹理与 JPG 噪点
- 色差用 **CIEDE2000**（Lab 空间），比 RGB 距离更贴近人眼；已用 CIE 官方 7 组标准数据校验通过
- 内置固定色卡 **思博尔毛绒 1–21 色**，色值从实物色卡照片按真实网格提取
- 也支持自己扩展色卡：上传色卡照片（框选网格自动切格 + 批量编号）、粘贴表格、手动加色
- 自定义色卡存浏览器 localStorage；色卡是通用的，不区分用户

- 浅蓝主题界面，单文件运行，无需后端

## 关于内置色卡

内置 21 色的色值来自实物色卡照片，用**真实网格边界**（而非简单等分）切分，并逐格验证过内部颜色一致性，确认无串色。

覆盖范围：**暖色系为主**——白、米白、浅黄、粉、珊瑚粉、玫红、正红、深红、酒红、亮黄、橘、卡其、棕、深棕。
**不含蓝、绿、紫等冷色系**。取到冷色时工具会给出最接近的一档，但 ΔE 会明显偏大（>20），这类结果只能作参考。

若需要冷色系，可另外拍一张色卡照片导入，工具支持多套色卡并存与切换。

注意：色值取自照片，拍照光线、屏幕显示与实物毛线之间存在天然色差，推荐色号仅供参考，最终以实物比对为准。

## 本地运行

纯静态单文件页面，直接用浏览器打开 `index.html` 即可；或在该目录执行：

```bash
python3 -m http.server 8000
```

然后访问 http://localhost:8000 。
