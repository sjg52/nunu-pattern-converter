# 努努排版小工具

努努图纸部件识别与自动排版工具。上传努努图纸（支持多图、非白底色），自动识别部件并基于 MaxRects 算法进行无重合排版，可设置部件间距、来源尺寸等参数，适合手工/缝纫制版场景下的图样排料。内置**义乌思博尔色卡（1–210 色）**，可取色匹配色号。

## 功能特性

### 图纸排版
- 多图上传，自动识别图纸中的部件
- 识别后可手动删除/恢复任意部件（悬停可在预览图上定位）
- 排版按需生成：改参数、删部件只标记为待更新，点「生成排版」才真正计算，避免反复重算卡顿
- 形状感知的 MaxRects 无重合排版（碰撞检测优化）
- 支持非白色底色图纸
- 可配置部件间距、来源尺寸等参数

### 配色推荐（色卡匹配）
- 色卡固定为 **义乌思博尔色卡**，共 210 色（1–210），不支持增删改，保证任何人看到的是同一套色号
- 每个色块**直接显示实物色卡照片上的那一格**（不是色块填充），颜色与实物一致，不用先想象再对照
- 上传参考图（娃娃照片 / 图纸 / 布料图，与排版用的图纸互不影响）→ 在图上点一下取色 → 输出最接近的色号 Top 8
- 取色用**周围一圈的中位色**，抗线稿边缘、毛绒纹理与 JPG 噪点
- 色差用 **CIEDE2000**（Lab 空间），比 RGB 距离更贴近人眼；已用 CIE 官方 7 组标准数据校验通过
- 结果同时给出 HEX、ΔE、相似度百分比，可并排对比照片色块

### 数据存后端
色卡数据放在后端 `data/palette.json`，由本地服务 `server.js` 通过 `GET /api/palette` 提供；前端启动时优先读接口。
直接双击打开 `index.html`（没有服务）时，自动回退到 `assets/palette-seed.js` 里的同源副本，功能不受影响。

## 关于色卡

- 210 个色值全部来自你拍的 5 张实物色卡照片（每张两页，每页 3 列 × 7 行）。
- 取色方式：先按印刷结构定位每页的格线（整页统一节距 + 倾斜修正，避免个别格子串到相邻色块），再在格内搜索「最纯净」的取色窗，避开印字、缝线和白色空隙。
- 色值做了**轻微白平衡**：用格与格之间的纸白作参考，把 5 张照片的色偏拉到同一基准，跨照片比色才可靠（校正幅度约 3%–10%，不会把亮黄推爆）。
- 色块图片与色值同源，所以「看到的」和「匹配出的」是同一个颜色。

注意：色值取自照片，拍照光线、屏幕显示与实物毛线之间存在天然色差，推荐色号仅供参考，最终以实物比对为准。

## 本地运行

需要 Node.js（14+），无第三方依赖：

```bash
node server.js          # 或 npm start
```

然后访问 http://localhost:5179 。色卡接口：http://localhost:5179/api/palette 。

也可以直接用浏览器双击打开 `index.html`（不启动服务），此时色卡读本地副本 `assets/palette-seed.js`。

## 目录结构

```
nunu-pattern-converter/
├── index.html             # 应用主体（样式 + 脚本）
├── server.js              # 本地服务：静态站点 + /api/palette
├── package.json
├── data/
│   └── palette.json       # 色卡数据（后端唯一数据源，210 色）
├── assets/
│   ├── pal-1..5.jpg       # 色卡照片（色块显示用，从原图缩放而来）
│   └── palette-seed.js    # palette.json 的离线副本（由同一份数据生成）
├── source-photos/         # 原始色卡照片（留档，便于日后重做）
└── README.md
```

## 维护提示

- 改色卡只改 `data/palette.json`，并同步生成 `assets/palette-seed.js`（内容必须与 json 完全一致，否则离线与在线会不一致）。
- 换新照片重做色卡时，需重新校准网格；`source-photos/` 里保留了本次使用的 5 张原图。
