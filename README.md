# 努努排版小工具

努努图纸部件识别与自动排版工具。上传努努图纸（支持多图、非白底色），自动识别部件并基于 MaxRects 算法进行无重合排版，可设置部件间距、来源尺寸等参数，适合手工/缝纫制版场景下的图样排料。内置**义乌思博尔（1–210 色）**与**紫誉 / 大狮子布艺（1–200 色）**两套色卡，可取色匹配色号。

## 功能特性

### 图纸排版
- 多图上传，自动识别图纸中的部件
- 识别后可手动删除/恢复任意部件（悬停可在预览图上定位）
- 排版按需生成：改参数、删部件只标记为待更新，点「生成排版」才真正计算，避免反复重算卡顿
- 形状感知的 MaxRects 无重合排版（碰撞检测优化）
- 支持非白色底色图纸
- 可配置部件间距、来源尺寸等参数

### 导出底色（新增）
下载前可选三种底色，**预览即导出效果**，文件名自动带底色标记：

| 选项 | 用途 | 文件名示例 |
|---|---|---|
| 白底 PNG | 直接打印最省事，与旧版行为一致（默认） | `图纸_29.7x21cm_300dpi_白底.png` |
| 透明 PNG | 叠到彩色/花纹纸上不挡底，抠图、贴纸排版用 | `图纸_29.7x21cm_300dpi_透明.png` |
| 自选底色 | 取色器或输入 `#RRGGBB`，对齐布样、深色纸、米黄纸 | `图纸_29.7x21cm_300dpi_f2ede2.png` |

- 透明模式下预览用棋盘格衬底，能直接看出哪些区域是空的
- 部件是按真实轮廓裁切的带透明通道画布，铺任意底色都保留原始形状，不会带出方形白块
- 改底色只重画预览（不重算排版），颜色拖动时做 120 ms 防抖

### 配色推荐（色卡匹配）
- 色卡库按**厂家**组织：点击厂家名称展开看色卡，再点一次收起（默认收起）
- 厂家写死为三个槽位，目前已录入**义乌思博尔**（1–210 色）和**紫誉 / 大狮子布艺**（1–200 色）；第三个槽位留空，补上数据后自动出现在页面上
- 色卡不支持在页面上增删改，保证任何人看到的是同一套色号
- 匹配时**跨全部有数据的厂家一起比**，结果每条都标了厂家名，方便直接下单
- 每个色块**直接显示实物色卡照片上的那一格**（不是色块填充），颜色与实物一致，不用先想象再对照
- 上传参考图（娃娃照片 / 图纸 / 布料图，与排版用的图纸互不影响）→ 在图上点一下取色 → 输出最接近的色号 Top 8
- 取色用**周围一圈的中位色**，抗线稿边缘、毛绒纹理与 JPG 噪点
- 色差用 **CIEDE2000**（Lab 空间），比 RGB 距离更贴近人眼；已用 CIE 官方 7 组标准数据校验通过
- 结果同时给出 HEX、ΔE、相似度百分比，可并排对比照片色块

### 数据存后端
每个厂家的色卡数据放在后端 `data/` 下，由本地服务 `server.js` 提供接口；前端启动时逐个读取。厂家清单写死在 `index.html` 的 `VENDOR_DEFS`（每项含 `key` / `name` / `src`，`src` 为 `null` 表示暂未录入，不显示在页面上）。
直接双击打开 `index.html`（没有服务）时，自动回退到 `assets/palette-seed.js` / `assets/palette-seed2.js` 里的同源副本，功能不受影响。

## 关于色卡

- 义乌思博尔：1–210 色，取自 5 张实物照片（每张两页，每页 3 列 × 7 行）。
- 紫誉 / 大狮子布艺：1–200 色，取自 9 张实物照片（共 10 页，最后一页是左右两页合影；每页 3 列 × 7 行）。该卡 201–210 为空位（无色布片），只录了 1–200。
- 取色方式：先按印刷结构定位每页的格线（行用色块边界梯度拟合，列用「行内颜色最均匀」搜索列位置，避免个别格子串到相邻色块），再在格内取中位色，避开印字、缝线和白色空隙。
- 色值做了**轻微白平衡**：用色卡纸白作参考，把各张照片的色偏拉到同一基准，跨照片、跨厂家比色才可靠。
- 色块图片与色值同源，所以「看到的」和「匹配出的」是同一个颜色。

注意：色值取自照片，拍照光线、屏幕显示与实物毛线之间存在天然色差，推荐色号仅供参考，最终以实物比对为准。

## 本地运行

需要 Node.js（14+），无第三方依赖：

```bash
node server.js          # 或 npm start
```

然后访问 http://localhost:5179 。色卡接口：`/api/palette`（义乌思博尔）、`/api/palette2`（紫誉 / 大狮子布艺）。

也可以直接用浏览器双击打开 `index.html`（不启动服务），此时色卡读本地副本 `assets/palette-seed.js` / `palette-seed2.js`。

```

├── index.html             # 应用主体（样式 + 脚本）

├── package.json
├── data/
│   ├── palette.json       # 义乌思博尔色卡（1–210）
│   └── palette2.json      # 紫誉 / 大狮子布艺色卡（1–200）
├── assets/
│   ├── pal-1..5.jpg       # 义乌思博尔色卡照片（色块显示用）
│   ├── pal2-1..9.jpg      # 紫誉 / 大狮子布艺色卡照片
│   ├── palette-seed.js    # palette.json 的离线副本
│   └── palette-seed2.js   # palette2.json 的离线副本
├── source-photos/         # 原始色卡照片（留档，便于日后重做）
└── README.md
```

## 维护提示

- 改色卡只改对应的 `data/palette*.json`，并同步重新生成 `assets/palette-seed*.js`（内容必须与 json 完全一致，否则离线与在线会不一致）。
- 换新照片重做色卡时，需重新校准网格；`source-photos/` 里保留了两次使用的原图（pal-* 义乌思博尔，pal2-* 紫誉 / 大狮子布艺）。
- 新增厂家：在 `data/` 放 json、在 `server.js` 的 `PALETTE_ROUTES` 加一条路由、在 `index.html` 的 `VENDOR_DEFS` 填 `name` 与 `src` 即可（第三槽位 key 为 `vendor3`）。

## 小红书小工具离线包（`.skill/minitool-zip-builder` 规范）

本工具另有一份「离线 H5」产物，可上传小红书小工具平台：

- **产物**：`nunu-pattern-tool.zip`（可直接上传），构建源目录 `dist/`
- **构建**：`node tools/build-minitool.js`（依赖已随包放在 `tools/vendor/jpeg-js`，无需 npm install）
- **打包**：`python tools/pack-minitool.py`（平台要求**全部文件平铺在 zip 根目录**、条目名用正斜杠且不含 `..` / 前导 `/`，不要用 PowerShell `Compress-Archive`）
- **与网页版的差异**（容器限制导致，改动都在构建脚本里自动完成）：
  | 项 | 网页版 | 小工具包 |
  |---|---|---|
  | 脚本位置 | `<script>` 写在 HTML 内 | 外置为 `app.js`（容器 CSP 禁止内联脚本） |
  | 色卡数据 | `fetch('/api/palette')` | 直接读包内 `palette-seed*.js`（容器不联网） |
  | 导出 PNG | `a[download]` | `xhs.miniTool.saveImageToPhotosAlbum`；无容器能力时页内展示供截图（底色选择同样生效，透明 PNG 的 alpha 原样保留） |
  | 语法 | 含可选链 | 降级为 ES2017（Chrome 61 基线） |
  | CSS | flex `gap` | 增加行为检测回退（`html.no-flex-gap`），grid 用 `grid-gap` |
  | 照片 | 1100px / 2.82MB | 800px / 1.42MB（按色块展示尺寸重压） |

- **交付前须由用户完成**：创服平台模拟器验证 → Android 真机扫码 → iOS 真机扫码；Chrome 61 兼容性与真机性能**未实测**。
